# Task 1: Linux Terminal Navigation & Environment Exploration

## Objective
To learn how to navigate the Linux filesystem, explore the terminal environment, and create directories and files.

## Commands Practised

- pwd: Displays the current directory.
- whoami: Displays the current username.
- hostname: Displays the hostname.
- date: Displays the current date and time.
- ls: Lists files and directories.
- ls -l: Displays detailed file information.
- ls -la: Displays all files, including hidden files.
- cd ..: Moves to the parent directory.
- cd -: Returns to the previous directory.
- cd ~: Moves to the home directory.
- mkdir -p: Creates directories.
- touch: Creates empty files.
- find: Searches for files and directories.

## What I Learned
I learned how to navigate the Linux filesystem using absolute and relative paths. I also learned how to identify my current location, inspect files, create directories, and create README files.
