Task 2: File and Directory Management

Objective

To practise creating, inspecting, copying, moving, renaming, and removing files and directories using Linux commands.

Commands Practised

- "mkdir": Creates directories.
- "touch": Creates empty files.
- "echo": Writes text into files.
- "cat": Displays file contents.
- "head": Displays the beginning of a file.
- "tail": Displays the end of a file.
- "wc -l": Counts the number of lines.
- "cp": Copies files.
- "mv": Moves or renames files.
- "rm": Removes files.
- "ls -l": Displays files with permission information.

Explanation of Commands

- "touch" creates empty files.
- "cp" copies a file from one location to another.
- "mv" moves or renames files
- "rm" removes files.

Output Redirection

The ">" operator writes content into a file and replaces existing content.

The ">>" operator appends new content to the end of a file without removing the previous content.

File Permissions

I used "ls -l" to inspect file permissions. I learned that "r" means read, "w" means write, and "x" means execute. The command also displays the file owner and other information.

What I Learned

I learned how to manage files and directories using Linux commands. I also practised writing and reading file contents, copying and moving files, renaming files, deleting files, and understanding basic permissions.
